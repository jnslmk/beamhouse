## What each one actually says

- **[ADR-0001](0001-gdtf-and-ofl-as-definition-formats.md)** — GDTF **and** OFL, both resolving to one internal fixture model. Licensing decided it: GDTF Share grants no redistribution right, so only OFL can populate a bundled library. QLC+ rejected as a runtime format, kept as a migration source.
- **[ADR-0002](0002-bridge-speaks-both-sacn-and-artnet.md)** — The bridge receives sACN **and** Art-Net at once. Not the design's port-binding argument, which measured false — gled2 has no sACN at all and must stream alongside Mizer.
- **[ADR-0003](0003-fixture-id-is-the-only-identity.md)** — The integer fixture id is the only identity. It is the one key both Mizer and MVR supply, and the one an operator reads off the console.
- **[ADR-0004](0004-gdtf-ts-is-a-published-gdtf-only-package.md)** — `gdtf-ts` parses and resolves GDTF and nothing else — MIT, runtime-agnostic, no renderer types, no OFL, no MVR. Published to npm, gated on M4.
- **[ADR-0005](0005-emitter-grouping-is-by-dmx-stride.md)** — Group emitters on **DMX stride**, never on spatial evenness. The ticket's own rule was falsified by its own test artifact. A strip never crosses a fixture.
- **[ADR-0006](0006-bridge-is-typescript-on-bun.md)** — The bridge is TypeScript on Bun — neither option as posed. Bun's multicast receive measured indistinguishable from Node's; Rust's one real win was worth ~60 lines.
- **[ADR-0007](0007-one-universe-space-sacn-numbered.md)** — Art-Net Port-Address *p* → universe *p* + 1, mapped in the bridge and nowhere else. Fixes a silent one-off that ADR-0002 assumed away.
- **[ADR-0008](0008-colour-space-is-assumed-transfer-function-is-read.md)** — Assume the colour space (GDTF defaults to sRGB anyway), read the transfer function where it is declared. One assumption at one site, behind a branded `LinearRGB` type.
- **[ADR-0009](0009-deployment-is-inferred-from-origin.md)** — One source, two builds, three deployments. Deployment is inferred from the page's own origin, never compiled in — which makes the mixed-content trap structurally impossible.
- **[ADR-0010](0010-resolution-is-total-the-renderer-selects-by-attribute.md)** — Resolution is total; the renderer selects by attribute. Amends ADR-0008.
- **[ADR-0011](0011-a-fixture-is-addressed-per-break.md)** — A fixture carries one address **per break**, so it can span universes — and is stale if *any* break is stale. Mizer's singular pair is the degenerate one-break case.
- **[ADR-0012](0012-beamhouse-may-define-pixels-placement-mints-nothing.md)** — Beamhouse may carry its own `bhs:` pixel definitions, because gled2 streams universes Mizer never patched. **Placement still mints nothing** — a local fixture has a definition, an address and a *negative* id, which Mizer's `u32` cannot collide with.
- **[ADR-0013](0013-atmosphere-is-one-closed-form-scattering-term.md)** — A constant-density single-scattering term ships in v1, closed-form because it drops extinction and anisotropy. The deferred tier begins at the **second sample of `density(p)`**. Also corrects `BeamAngle` to the **full** cone angle at six sites, where it was called a half-angle. Amends ADR-0010.
- **[ADR-0014](0014-the-agent-surface-is-two-surfaces.md)** — "The agent surface" was two surfaces sharing a word. The **look** half is a feed and is `generated`, carrying DMX slot values so it exercises the real pipeline; it takes the slot ADR-0009 emptied by deleting `relay`, and is shared with §9.2's demo motion mode. The **scene** half is not a feed at all.
- **[ADR-0015](0015-agent-control-is-mcp-over-the-bridge-control-channel.md)** — An agent arranges the rig through an **MCP server** speaking the bridge's control channel. The bridge forwards **opaque envelopes it never opens**, so ADR-0006's ignorance survives; exactly one client owns the scene, commands are loopback-only, and capture is a command.
- **[ADR-0016](0016-every-scene-mutation-is-one-undo-grained-command.md)** — One command layer, with the UI and the agent as two front-ends. A command is **undo-grained** — one command, one undo entry, one thing a person would say out loud. Constrains #35.
- **[ADR-0017](0017-shaders-are-hand-written-glsl-webgpu-is-out-of-scope.md)** — Hand-written GLSL on `WebGLRenderer`, and **one** shader pair: the strip is a texture `map`, not a shader. WebGPU is **out of scope**, because the ADR-0013 tier is fragment-shader raymarching that WebGL2 reaches; only a *simulated* atmosphere would reopen it. `postprocessing` leaves the dependency table and `three` pins exactly.
- **[ADR-0018](0018-signal-health-is-one-per-universe-snapshot.md)** — One `universes` snapshot replaces `stale` and `sacn_source`. Blind and priority are **sACN-only** and report `null` on Art-Net, which means *unknown*, not *not blind*; the stale threshold is **per transport**, because 2.5 s is E1.31's and Art-Net re-transmits an idle input only every ~4 s. Signal health belongs to the **feed**, so it is unreachable — not false — off a live one. Amends ADR-0007's reach: the transport returns on the **control channel**, never in the frame.
- **[ADR-0019](0019-the-intensity-map-is-relative-not-photometric.md)** — The mode ships in v1, reads **resolved per-emitter intensity**, and is **not called false colour**. Measured: every `Dimmer` `ChannelFunction` in all six profiles is `PhysicalUnit="None"` over 0 → 1, and no profile carries a credible `LuminousFlux` — so v1 makes **no photometric prediction**, stated as a non-claim rather than left as a gap.
- **[ADR-0020](0020-the-live-loop-serves-patch-files-not-consoles.md)** — Beamhouse names no console list. The live repatch loop serves any patch file that sits on a **watchable path** and names its definitions in a **library Beamhouse resolves**. Mizer is the only source that passes; BlinderKitten and MagicQ fail on the second condition, because both flatten a GDTF into their own channel model and discard the definition identity. Measured: **no console on this machine writes an MVR** — Mizer exports CSV, BlinderKitten and MagicQ only *import* it — so MVR import serves **design and previz tools**, not consoles. Amends ADR-0003 with an MVR ingest ladder and a UUID reconciliation hint; re-targets M5b to BlenderDMX; unblocks #30.
- **[ADR-0021](0021-mvr-xchange-is-out-of-scope-the-patch-seam-is-format.md)** — MVR-xchange is **out of scope, not deferred**: of its six named peers only grandMA3 is a console, and that population already reaches Beamhouse through MVR *file* import. The seam that makes re-entry cheap is **format**, not delivery — `parse(bytes) -> Patch` with `mizer`, `mvr` and `snapshot`, while watched/one-shot/inline stays outside it, so a pushing station would be a new byte source reusing the `mvr` parser unchanged. Measured: the ticket's "three real sources" counted drag-and-drop, which is a **transport**, and missed the **URL fragment** — M3a needs a patch with no file on disk, and §9.2's local-path `.bhs` made that clause unsatisfiable. `bhs:` local fixtures are a **merge contribution**, not a source. M5b's done-when re-targeted again: **BlenderDMX is not on this disk**, so a milestone clause may name a file in this repo or a capability, never a third-party tool.
- **[ADR-0022](0022-beamtype-selects-the-path-stride-aggregates-within-it.md)** — **`BeamType` selects the render path; ADR-0005's stride aggregates within it**, so the two rules never claim the same emitter and no precedence clause is needed. `Wash`/`Fresnel`/`PC`/`Spot`/`Rectangle` add a cone; `None`/`Glow` do not. The paths are **not exclusive**: one always-on emissive body, plus a conditional cone — which is what makes a `Wash` mover visible before any atmosphere exists. Measured: the ticket's premise that no profile on disk forces the conflict is **false**, and in the opposite polarity — the WLED profile's three `Glow` beams are non-strided *and* it ships **zero `<Model>` elements**, so neither rule had an answer to offer; a missing-geometry `Glow` beam now falls back to a `BeamRadius` body and a surfaced defect. The strip path textures the run's **common parent**, not the referenced emitter. The STAR-TENT spoke copies `MarkeEigenbau`'s shape onto the build123d `led_profiles` mesh — a **stadium, not a cylinder** — with the **diffuser** as the emissive surface, simplified upstream to 544 verts from 22,660.
- **[ADR-0023](0023-the-chip-bar-is-the-navigation.md)** — The screen was the one gap the size of the ones the other ADRs closed: `DESIGN.md` described a renderer, a resolver, a bridge and a wire protocol and **never described the UI**. Viewport-dominant, **nothing docked**: eight state chips are the navigation — each shows its value and opens **one** tabbed overlay (`Fixtures · Objects · Universes · History · Issues`) at its tab — after grandMA3, which docks nothing at all. §13's signal inventory therefore costs **no layout**, since the bar is already the status line. No ninth chip for issues: the count rides **Patch**, because every issue class originates in an ingest. A per-chip popover *plus* a tab was rejected as duplication — §13.2's read-out has seven columns. First run is the empty grid, not a start screen (§4.6 auto-saves); the picker takes Mizer YAML and MVR and refuses `.olga`/MagicQ CSV **with the reason**. The Pages viewer runs the same shell with bridge-dependent chips **absent, not greyed** — §13's *unreachable, not false*.
- **[ADR-0024](0024-a-selection-hold-pins-the-render.md)** — Beamhouse never sends DMX, so a fixture can be mid-chase while you drag it, and **not one of the five surveyed products has this problem**: each is either the console or has a programmer. A `Hold` chip **pins the render of the selection**; frames keep arriving and the feed never notices. Render-side only, so it sits under ADR-0018 untouched — a held universe is not stale and must never read as stale — and it is **not** a command under ADR-0016, because it mutates no scene state. A global synthetic-look edit mode was rejected for throwing away the reason you are in the app: you position fixtures *against what they are doing*.
- **[ADR-0025](0025-trust-and-provenance-marks-are-additive.md)** — Staleness, the override layer and patch faults are **additive screen-space marks**, never a change to how the fixture is shaded. §13.3 supplies the proof rather than a preference: *"a fixture at zero and a fixture whose data stopped look identical at full brightness zero"*, so every subtractive cue — dimming, greying, desaturating — modulates something a dark fixture is not rendering and **vanishes in exactly the case that matters**. A stale fixture keeps drawing its frozen values at full strength; the badge is the only thing that says so. Marks **compose** where shading cannot, and there is **one per fixture, never per break** (ADR-0011). Gives ADR-0012's extent mismatch, ADR-0020's synthesised ids and §4.5's orphaned overrides the shared **Issues** surface all three demanded and none of them located. Records that a **missing definition is not proxy geometry**: per §9.2 as corrected by #27, no definition means no `PrimitiveType`, so it draws as a placeholder and nothing more.
- **[ADR-0026](0026-the-control-channel-carries-requests-only-one-class-is-a-command.md)** — ADR-0016 closed with *"the MCP tool vocabulary is whatever the command layer holds"*, and that was **wrong on #37's own acceptance case**: *"enumerate the rig … capture"* opens with a read and ends with a screenshot, neither of which mutates scene state. The word `command` was doing two jobs — ADR-0015's forwarded **envelope** and ADR-0016's **undo unit**. The channel now carries **requests** in four classes — `command` (mutates the scene, undoable), `query` (reads, plus `undo`/`redo`, `select`, `camera.set`, `hold`), `capture`, `look` — and only the first is the command layer. Three rules follow: a command **carries its target ids**, so the selection and the snap step are UI-side inputs the agent never inherits; **commands write everything in the `.bhs` except `patch`, ingests write only `patch`**, which is §4.5 generalised and keeps §4.6's watcher from pushing entries onto your undo stack; and **one shared stack**, agent rows marked, because *"undo the last thing that happened"* is the only question anyone asks at 4pm. History is a **journal** — commands, where the cursor stops, and ingest **events**, which are not undoable.
- **[ADR-0027](0027-ownership-is-implicit-and-a-non-owner-stops-saving.md)** — ADR-0015 fixed *that* one client owns and not *how*. First: this bites rarely — the MCP server is a client of the *control channel* and the owning **page** applies requests, so one tab plus an agent has no contention; ownership is contended between **pages**, which only §09's *"LAN too"* produces. **First connection owns implicitly** (no ceremony in the single-tab case, which is every case on the bench), **takeover is one click** behind a confirmation naming the holder, and release is on socket close **or ~15 s of silence** — because a slept laptop otherwise holds the rig with no way to take it back. A woken page returns as a **non-owner** and must re-claim. The trap ADR-0015 named turns out to be the **auto-save, not the following**: a non-owner adopts the owner's scene, follows its commands, and has §4.6's IndexedDB save **suspended**. Following is cheap because ADR-0016 made commands undo-grained.
- **[ADR-0028](0028-a-capture-is-a-handle-fetched-over-http.md)** — ADR-0015 put captures on the frame socket, reasoning §06 could report the frame they cost. **§07 is one socket**, so a capture does not share the wire, it **blocks** it — and the drop is indistinguishable in §13 from a real fault, meaning the visualiser would manufacture the diagnostic it displays. `capture` now returns a **handle** the MCP server `GET`s over the `http://localhost` the bridge already serves: **no bulk touches the DMX socket**, and the bridge gains a route, not a concept. `maxEdge` **1280** and quality **0.8** by default so the normal path **cannot** reach the **1 MB** cap; the reply states dimensions, size and whether it downscaled, and exceeding the cap is an **error naming the size**, never a truncated image. Every capture is **stamped with its feed** — ADR-0018's `null` rule applied to images: a `live` capture is one instant of a chase and must not be diffed, and an agent that cannot tell would measure chase phase as if it were its own edit.
- **[ADR-0029](0029-the-bridge-detects-contention-and-never-arbitrates.md)** — The bridge **detects** contention and **never arbitrates**: Beamhouse never sends DMX, so its claim is *this is what the network is doing*, and a visualiser that picks a winner renders a fiction no fixture sees — real fixtures each run their own merge. Four premises fell. The rig has **no sACN in it at all** (Mizer's two connections are both `type: artnet`), so priority and blind are `null` on every universe today and the sACN case #38 asked about cannot arise here — [#44](https://github.com/jnslmk/beamhouse/issues/44) moves it, changing **no** Beamhouse universe number. ADR-0007's *collision-free by construction* is **withdrawn** — *p* + 1 lands inside sACN's own range, so the real case is **cross-transport** contention, which the ticket never raised. ADR-0018 promised a `contended` flag with **no field on the wire to carry it**. And `sacn` npm's `MergingReceiver` — the free-looking option — is deprecated, self-described as untested, and silently wrong for every universe ≥ 10 (`parseInt(u.toString(36), 10)`: 10 → `NaN`, 100 → `2`). So §07's record becomes **source-shaped**; the stale threshold is per source with an **all**-rollup, deliberately the opposite of ADR-0011's **any**-rollup on breaks; `Stream_Terminated` is consumed; the bridge takes over sequence tracking (E1.31's −20..0 window, and Art-Net's sequence **0 means disabled**); one packet contends with **no debounce**; and a contended fixture is marked *disputed*, distinct from stale's *old*. Per-slot HTP/LTP merging is **out of scope**. Amends ADR-0007, ADR-0018.

## Writing a new one

**Get the number from `tools/adr.sh next`, not from `ls`.** It scans the working tree, `origin/main` and every other local and remote ref, because a number claimed on an unmerged branch is still claimed.

```
git fetch --all
tools/adr.sh next
```

This is not defensive pedantry. On 2026-09-02 two agent sessions in parallel worktrees each read `0008` as the maximum and each wrote an `0009` ([#34](https://github.com/jnslmk/beamhouse/issues/34)). `DESIGN.md` then invented `ADR-0009a` to work around it, which is what kept the clash invisible for a day. Renaming cost eleven citation sites across four files, this index and the map.

Then:

1. **File name** `NNNN-kebab-slug-of-the-title.md`, the slug taken from the title's first clause.
2. **First line** `# ADR-NNNN: <title>` — the number appears in both, and `tools/adr.sh check` enforces that they agree.
3. **Front matter**, in this order, only the fields that apply:

   | Field | Meaning |
   |---|---|
   | `Status:` | `Accepted`, or `Superseded by ADR-NNNN` |
   | `Date:` | ISO, the day it was accepted |
   | `Decides:` | the one wayfinder ticket this ADR *is* the resolution of. **At most one ADR may claim any given ticket** — enforced |
   | `Surfaced by:` | a ticket that exposed the question without being about it (ADR-0007) |
   | `Source:` | for an ADR with no ticket behind it at all (ADR-0003) |
   | `Informed by:` | supporting tickets (ADR-0001) |
   | `Amends:` / `Amended by:` | between ADRs, always written on **both** sides |
   | `Renumbered:` | only when a published number changed (ADR-0011) |

4. **Body**: `## Context`, `## Decision`, optionally `## Considered options`, then `## Consequences`.
5. **Add the row to this file in the same commit.** An ADR missing from the index is unfindable; an index row with no ADR is the cheapest collision marker there is. `tools/adr.sh check` enforces both directions.

## Checking

```
tools/adr.sh check
```

Verifies unique numbers, filename/title agreement, required front matter, that no two ADRs claim the same `Decides:` ticket, that the index and the directory match both ways, and that every relative Markdown link in the repo resolves. Run it before pushing anything that touches `docs/adr/`.

## Numbers never get reused

`0009` means the deployment ADR and will not come to mean anything else, even though a per-break ADR briefly had it. Commits and issue comments from before 2026-09-02 that say "ADR-0009" and mean per-break are history and stay as written — [ADR-0011](0011-a-fixture-is-addressed-per-break.md) carries a `Renumbered:` line so they stay followable.
